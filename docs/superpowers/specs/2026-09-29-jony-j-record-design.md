# Jony J 唱片内页风介绍站设计

## 目标

制作一个介绍说唱歌手 Jony J 的单页网站，让访客快速了解歌手与代表作品，并可在页面内试听可用歌曲。当前仓库为空，没有可复用的框架、素材或组件。

## 视觉与内容

采用唱片内页风：深色底、低饱和纸张与金属唱片质感、醒目的标题排版，以及专辑卡片式作品陈列。页面包含首屏介绍、简短人物简介、代表作品列表和页面内播放器区域。移动端纵向浏览，桌面端使用更宽松的唱片陈列布局。人物事实及作品名称需来自可核验的公开来源；页面展示艺人资料页中的公开宣传照和官方音乐平台专辑封面，并在页面标注图片来源；图片保持远程引用，不下载重托管。

## 播放方式

用户要求站内播放，但没有提供本地音频或授权音源。因此只采用音乐权利方/平台提供的官方嵌入播放器或官方试听组件，不抓取音频、不自行代理音频 URL。最初选用 Apple Music，后按用户要求改为 YouTube 官方艺人频道中由 SHOOC 提供的官方音频。点击作品后，在站内播放器区域载入对应 YouTube 嵌入播放器。播放器在部分网络环境可能不可访问，页面应提示平台可用性限制。

## 技术与交互

仓库空白，先选择最小依赖的静态单页实现，除非部署目标带来明确框架约束。播放器由用户显式点击后加载，不自动播放；切换曲目时替换当前播放器，提供曲名与播放状态。嵌入加载失败时显示清楚的失败状态。布局适配手机与桌面，键盘可操作，并尊重减少动态效果设置。

## 验收标准

- 首页清晰呈现 Jony J 的介绍及代表作品，整体符合唱片内页风格。
- 至少一首经验证有官方嵌入来源的作品能在页面内启动播放；如果官方来源不开放嵌入，则明确报告阻塞，不以非官方音频替代。
- 播放器只在用户选曲后加载，切换曲目后旧播放器被替换。
- 移动端布局可用，页面无自动播放。
- 人物介绍和作品条目有可追溯公开出处；外部嵌入和作品访问限制在界面中有合理呈现。
